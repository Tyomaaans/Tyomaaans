# Hi, I'm Tyomaaans

**Backend development · Go · APIs**

I build backend services with Go, PostgreSQL, and Redis, focusing on authentication, data workflows, and API integrations. I also use React and TypeScript to build interfaces that connect to those services.

My portfolio includes session management, URL shortening, product catalogues, sandbox payment integrations, and WebSocket chat.

## What I work on

- **APIs & authentication:** REST endpoints, request validation, JWT, refresh-token rotation, session management, and role-based access control.
- **Data & background processing:** database transactions, caching, rate limiting, RabbitMQ workers, and transactional outbox workflows.
- **Application integration:** React interfaces, payment providers, webhook processing, and real-time communication.
- **Deployment & testing:** Docker Compose and Nginx configuration, GitHub Actions workflows, and backend, frontend, and browser tests.
